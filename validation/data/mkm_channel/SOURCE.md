# Moser-Kim-Mansour channel DNS

Downloaded 2026-10-30 from the authors' public database:
https://turbulence.oden.utexas.edu/MKM_1999.html

`chan590.means` is the unmodified freely downloadable statistical data at
https://turbulence.oden.utexas.edu/data/MKM/chan590/profiles/chan590.means .
Retain its attribution header. Reference: Moser, Kim and Mansour (1999),
Physics of Fluids 11, 943-945. This is DNS validation, not a Fluent code result.
Despite the nominal Re_tau=590 name, the file's actual Re_tau is **587.19**;
the channel rig uses that value. Columns: y/h, y+, U/u_tau, dU/dy, W, dW/dy, p.

SHA-256: `878bc951794516b6136912f8f098cd6f2f96c4bbe7f21a8cea657ffb270d419d`.
